# Void Stasis

Paper plugin for Minecraft Java 1.21.11. Tag a player by hooking their Ender Pearl with a fishing rod, then reel them into the Void Stasis world.

Status: Stage 1 (project skeleton). Build with `./gradlew build` (JDK 21). Put `build/libs/VoidStasis-0.1.0.jar` in your server's `plugins/` folder.
